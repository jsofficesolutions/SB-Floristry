SB Floristry 🌸

SB Floristry is a premium, modern e-commerce platform and bespoke brand experience website designed for a family-run floristry business. Built on the Astro web framework and styled with Tailwind CSS, it bridges the beauty of traditional artisan floristry with modern headless web engineering. It integrates seamlessly with Shopify for headless product catalog management and GoCardless for automated, secure Direct Debit subscription setups.
